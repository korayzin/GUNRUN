📌 ADIM 3: Scroll View Ayarları Kontrol
   
   "Scroll View" seçili iken Inspector'da:
   
   Scroll Rect component:
   ☑ Vertical = AÇIK ✅
   ☐ Horizontal = KAPALI
   Movement Type = Elastic
   
   Content (Scroll View → Viewport → Content):
   - Anchor = Top Stretch
   - Pivot Y = 1
   - Script otomatik ekleyecek:
     • VerticalLayoutGroup
     • ContentSizeFitter

📌 ADIM 5: (Opsiyonel) Test Butonları Ekle

   1. Hierarchy → Right Click → UI → Button - TextMeshPro

      İsim: "ClearTestPlayersButton"

      - Add Test Players Button → AddTestPlayersButton'ı ata
      - Clear Test Players Button → ClearTestPlayersButton'ı ata

❌ "LEADERBOARD CONTENT YOK!" hatası:
   → LeaderboardUI'da "Leaderboard Content" atandı mı?
   → Scroll View → Viewport → Content'i sürükle!
   → En önemli adım bu! ⭐

❌ Hiçbir şey görünmüyor:
   → LeaderboardRow aktif mi? (hierarchy'de gri değil)
   → Console'da ne diyor? Logları kontrol et
   → Content objesi var mı?

❌ "FirebaseLeaderboardManager Instance bulunamadı!":
   → Scene'de FirebaseManager GameObject'i var mı?
   → Script eklenmiş mi?

❌ Firebase'e bağlanamıyor:
   → Internet bağlantısı var mı?
   → Firebase Database URL doğru mu?
   → Firebase Console'da Rules açık mı?

❌ Scroll çalışmıyor:
   → Scroll View'da Vertical checkbox'u açık mı?
   → Content'e VerticalLayoutGroup eklendi mi? (otomatik olur)
   → Content'e ContentSizeFitter eklendi mi? (otomatik olur)

```csharp
// Leaderboard'u göster
LeaderboardUI leaderboard = FindObjectOfType<LeaderboardUI>();
if (leaderboard != null)
{
    leaderboard.ShowLeaderboard();
}
```

Oyun bitiminde skor kaydet:

```csharp
// Skoru Firebase'e kaydet
FirebaseLeaderboardManager.Instance.SaveMaxScore(finalScore, (success) => {
    if (success) {
        Debug.Log("Yeni rekor!");
        // Leaderboard'u göster
        FindObjectOfType<LeaderboardUI>().ShowLeaderboard();
    }
});
```
