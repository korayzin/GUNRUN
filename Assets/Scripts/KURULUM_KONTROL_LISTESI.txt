📌 ADIM 1: LeaderboardUI GameObject'ini Bul
   Hierarchy'de şu yolu takip et:
   UI → GameMenu → Canvas → UIMenu → Panels → MainMenuPanel → InGame
   
   "Leaderboard" veya "LeaderboardFlow" GameObject'ini seç

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 ADIM 2: LeaderboardUI Component Referansları
   Inspector'da "LeaderboardUI" component'ini bul ve şunları ata:

   ⚠️ ÖNEMLİ - MUTLAKA ATANMALI:
   
   1️⃣ Leaderboard Panel:
      → Leaderboard GameObject'inin kendisini ata (veya altındaki Panel)
   
   2️⃣ Leaderboard Content: ⭐ EN ÖNEMLİ!
      → ScrollView → Viewport → Content'i buraya sürükle
      → Bu olmadan liste gösterilmez!
   
   3️⃣ Leaderboard Entry Prefab:
      → Assets/Gunrun 2.0/Prefabs 2.0/LeaderboardRow prefab'ını sürükle
      → Bu olmadan otomatik entry oluşturulur (yine de çalışır)
   
   4️⃣ My Score Text:
      → "Score (Text Mesh Pro UGUI)" objesini sürükle
      → Yoksa otomatik bulunmaya çalışılır
   
   5️⃣ Refresh Button: (Opsiyonel)
      → Refresh butonu varsa ata
   
   6️⃣ Loading Text: (Opsiyonel)
      → "Yükleniyor..." text'i varsa ata

   7️⃣ Max Entries: 50 (varsayılan değer)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 ADIM 3: LeaderboardRow Prefab'ını Düzenle
   
   1. Assets/Gunrun 2.0/Prefabs 2.0/LeaderboardRow'u aç
   
   2. LeaderboardRow GameObject'ine "LeaderboardEntryUI" script'ini ekle
      → Inspector → Add Component → LeaderboardEntryUI
   
   3. LeaderboardEntryUI referansları:
      - Rank Text → Rank text objesini ata
      - Name Text → Name/İsim text objesini ata  
      - Score Text → Score/Puan text objesini ata
      - Background Image → (Opsiyonel) Arka plan image'ı ata
   
   4. Prefab'ı kaydet (Ctrl+S)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 ADIM 4: ScrollView Ayarları Kontrol
   
   ScrollView seçili iken Inspector'da:
   
   ✅ Scroll Rect Component:
      - ☑ Vertical = AÇIK
      - ☐ Horizontal = KAPALI
      - Movement Type = Elastic
      - Elasticity = 0.1
      - Inertia = true
      - Scroll Sensitivity = 1
   
   ✅ Content (ScrollView/Viewport/Content):
      - VerticalLayoutGroup component'i eklenecek (otomatik)
      - ContentSizeFitter component'i eklenecek (otomatik)
      - RectTransform Anchor = Top Stretch
      - Pivot Y = 1

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 ADIM 5: FirebaseLeaderboardManager Kontrolü
   
   Hierarchy'de "FirebaseLeaderboardManager" GameObject'i olmalı
   
   ✅ Inspector'da:
      - Firebase Database Url = 
        https://gunrundata-default-rtdb.europe-west1.firebasedatabase.app
