Oyun kodundan açma:

```csharp
// GameManager veya UIManager'dan
LeaderboardUI leaderboard = FindObjectOfType<LeaderboardUI>();
if (leaderboard != null)
{
    leaderboard.ShowLeaderboard();
}
```

Oyun bitti, leaderboard göster:

```csharp
void OnGameOver()
{
    // Skoru kaydet
    FirebaseLeaderboardManager.Instance.SaveMaxScore(finalScore, (success) => {
        if (success) 
        {
            Debug.Log("Yeni rekor!");
        }
        
        // Leaderboard'u göster
        FindObjectOfType<LeaderboardUI>().ShowLeaderboard();
    });
}
```

Leaderboard kapatma:

```csharp
// Close butonu veya ESC tuşu
leaderboard.HideLeaderboard();
```
